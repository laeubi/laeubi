## Hi, I'm Christoph 👋

I maintain and contribute to open source projects that many companies silently depend on.
AI makes it cheap to write a code change, but someone still has to review, polish and shepherd it until it is accepted.
That is where I can be your **open source side-kick**.

### 🔭 What is currently in my scope

- 🔧 [Eclipse Tycho](https://github.com/eclipse-tycho/tycho): Maven build for Eclipse plugins, OSGi bundles and RCP applications
- 📦 [Eclipse M2E](https://github.com/eclipse-m2e/m2e-core): Maven integration for the Eclipse IDE
- 🔌 [Eclipse PDE](https://github.com/eclipse-pde/eclipse.pde): Plugin Development Environment
- 🖥️ [Eclipse Platform](https://github.com/eclipse-platform/): the IDE foundation including SWT
- 🧩 [OSGi](https://github.com/osgi/): specification, tooling and ecosystem
- ⚙️ [Eclipse Equinox](https://github.com/eclipse-equinox/): the OSGi framework implementation used by Eclipse, including p2 provisioning
- 🥒 [Cucumber Eclipse](https://github.com/cucumber/cucumber-eclipse): the Eclipse plugin for Cucumber

Missing something you rely on? [Suggest a project](https://github.com/laeubi/laeubi/issues/new?template=project-suggestion.yml) I should look at!
